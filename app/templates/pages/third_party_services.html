Third-Party Services

Flowboard works without connecting an external account. The integrations below are optional and are activated only when a user chooses to connect or configure them.

Google Calendar

When a user connects Google Calendar, Flowboard requests the following Google Calendar API scopes:

calendar.readonly lets Flowboard read the calendars available to the user and retrieve free/busy availability so its schedule can account for occupied time. calendar.events lets Flowboard create, update, and delete calendar events only when the user performs those actions from a dated Flowboard task.

Flowboard does not import Google Calendar events as Flowboard tasks and does not store event titles, attendees, or descriptions from Google. It caches the user-selected calendar list and busy time intervals for up to 15 minutes to plan around availability. Connected Google tokens are encrypted at rest. Disconnecting removes the local connection and tokens and makes a best-effort request to revoke the Google credential; existing Google Calendar events are not deleted by disconnecting.

The use of raw or derived user data received from Google Workspace APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google Calendar event content is not sent to AI providers. When a user asks the Flowboard assistant to schedule work, the request can include a derived daily total of calendar-busy minutes; it never includes Google event titles, attendees, descriptions, or OAuth tokens. Flowboard does not use Google Workspace API data to train or improve generalized or foundation AI models. See the Privacy Policy for the canonical data-handling description.

Microsoft 365 and Microsoft Graph

Flowboard can optionally connect Microsoft 365 / Outlook through Microsoft Graph. The current delegated scopes are Calendars.ReadWrite, User.Read, and offline_access. They identify the connected account, list writable calendars, read availability, and create, update, or delete events selected by the user. Flowboard does not claim that an unconfigured provider is available on this deployment.

AI providers and bring-your-own-key

Flowboard lets a user configure their own supported AI provider credentials. Requests use the selected provider and can contain the Flowboard board/task content needed for that request. The provider's terms and privacy policy apply to data sent to it. Credentials are encrypted at rest and are never rendered to public pages or returned in full to users.
